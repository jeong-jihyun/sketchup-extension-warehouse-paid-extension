[PRJ-0382] 스케치업(SketchUp) 익스텐션 웨어하우스 유료 확장 판매

3D 설계 프로그램 SketchUp 안에서 쓰는 작은 도구(예: 반복 작업 자동화, 자재 수량표 뽑기)를 루비 코드로 만들어 Extension Warehouse에서 판매. 근거: SketchUp 개발자 포럼 글에 유료 확장은 Trimble이 판매 수수료를 받고 개발자는 판매 수익을 얻는다고 나옴(수수료율 확인 못함, 실제 수익은 추정). 무자본 이유: 확장 개발은 루비 코드와 무료 SketchUp 체험 환경으로 시작 가능으로 보임(개발자 계정 조건과 무료 버전 제약은 확인 필요, 불가하면 제외 검토). 기존 PRJ-0380 등과 다른 플랫폼. 주의: 심사에 쓸 라이선스 접근 방법 제공 필요, 타인 코드 복제 금지. 출처: https://forums.sketchup.com/t/do-extension-developers-get-money-from-trimble/99122 , https://forums.sketchup.com/t/extension-warehouse-review-denied-because-paid-extension-requires-license-how-do-i-provide-reviewer-access/347199
